# packed_vector (ჯენერიკები - 60 ქულა)
თქვენი ამოცანაა იმპლემენტაცია გაუკეთოთ PackedVector ჯენერიკ სტრუქტურას, რომელსაც უნდა შეეძლოს განსხვავებული ზომის ელემენტების შენახვა.

PackedVector სტრუქტურას უნდა ქონდეს შემდეგი მეთოდები:

* void VectorInit(Vector\* v, int n); - ინიციალიზაცია უნდა გაუეკთოს მოცემულ ვექტორს. ვექტორში შესანახი ელემენტების რაოდენობა წინასწარ არის განსაზღვრული n-ით.
* void VectorDestroy(Vector\* v); - უნდა გაათავისუფლოს ვექტორის მიერ გამოყენებული დინამიური მეხსიერება.
* void VectorSet(Vector\* v, int index, int elem\_size, void\* elem); - მოცემულ index ინდექსზე უნდა ჩაწეროს elem\_size ზომის (ბაიტებში) ელემენტი რომელიც ინახება elem მისამართზე.
* void\* VectorGet(Vector\* v, int index, int\* elem\_size); - უკან უნდა დააბრუნოს index ინდექსზე შენახული ელემენტის მისამართი, ხოლო elem\_size ცვლადში უნდა ჩაწეროს ამ ელემენტის ზომა ბაიტებში. თუ მოცემულ ინდექსზე არ არის ელემენტი ჩაწერილი მაშინ elem\_size-ში უნდა ჩაწეროს 0, ხოლო უკან უნდა დააბრუნოს NULL.
* void VectorSwap(Vector\* v, int i, int j); - ადგილები უნდა გაუცვალოს i და j ინდექსზე მყოფ ელემენტებს.
* void VectorMap(Vector\* v, MapFn map\_fn, void\* aux); - ვექტორში შენახული ყველა არანულოვანი ზომის ელემენტისთვის უნდა გამოიძახოს გადმოცემული map\_fn ფუნქცია, რომელსაც არგუმენტებად უნდა გადასცეს: მიმდინარე ელემენტის ინდექსი, ამ ელემენტის ზომა ბაიტებში, ამ ელემენტის მნიშვნელობის მისამართი და VectorMap-ისთვის კლიენტის მიერ გადმოცემული aux მნიშვნელობა.

გარანტირებული ხართ რომ VectorSet გამოძახებისას elem\_size მეტი იქნება ნულზე.
ასევე VectorSwap გამოძახებისას არცერთი ელემენტი არ იქნება ნულოვანი სიგრძის.


**საკითხის შეფასების 100%-ის ასაღებად არ აღწეროთ დამხმარე struct-ები, წინააღმდეგ შემთხვევაში თქვენი ნამუშევარი შეფასდება 80%-ით.**


**ტესტების 50%-ში ვექტორში შენახული ყველა ელემენტს ერთი ზომა ექნება ბაიტებში.**

**VectorSwap შეფასდება საკითხის შეფასების 20%-ით, ხოლო VectorMap 10%-ით.**

**მეხსიერების არასწორად გამოყენების შემთხვევაში დაკარგავთ ტესტისთვის განკუთვნილი ქულის 15%-ს.**

**ნაკლები შეცდომები რომ დაუშვათ და კოდიც უფრო პატარა გამოგივიდეთ, გირჩევთ გამეორებადი ლოგიკა გაიტანოთ დამხმარე ფუნქციებად ან აღწეროთ მაკროების (define) გამოიყენოთ.**
