# transform (ნაკადები - 60 ქულა)
თქვენი ამოცანაა სიმულაცია გაუკეთოთ ხეების ზრდას. მოცემული გაქვთ N რაოდენობის ხე, რომლებიც ერთ რიგად არიან დარგული და გადანომრილები არიან 0-დან N-1 -ის ჩათვლით.  
ხეების ზრდა ხდება ეტაპოვრივად, ყოველ ეტაპზე თითოეული ხის სიგრძე იცვლება შემდეგი სტრატეგიით:
* თუ მიმდინარე ხე მის მეზობლებზე მაღალია, მაშინ მისი სიმაღლე რჩება უცვლელი.
* წინააღმდეგ შემთხვევაში კი ის სიმაღლეში უთანაბრდება მეზობელ ხეებს შორის ყველაზე მაღალს.
ხეები ზრდას წყვეტენ მას შემდეგ რაც მათი სიმაღლეები გათანაბრდებიან.

მაგალითად, თუ გვაქვს სამი ხე და მათი საწყისი სიმაღლეებია 1, 2 და 3, მაშინ პირველი ეტაპის შემდეგ მათი სიმაღლეები გახდება 2, 3, 3 ხოლო კიდევ ერთი ეტაპის შემდეგ 3, 3, 3 რის შემდეგაც ხეები შეწყვეტენ ზრდას.

თქვენ გევალებათ სიმულაცია ჩაატაროთ Transform ფუნქციის გამოყენებით, რომელიც ყოველი ხის ზრდის ლოგიკას უნდა უშვებდეს დამოუკიდებელ ნაკადში. ანუ Transform უნდა უშვებდეს N რაოდენობის ნაკადს. Transform ფუნქცია უნდა დაელოდოს ყველა გაშვებული ნაკადის დასრულებას და უკან უნდა დააბრუნოს თუ რამდენი ეტაპის შემდეგ მოხდა ხეების სიმაღლეების გათანაბრება.

**ნაშრომები შემოწმდება ხელით.**
