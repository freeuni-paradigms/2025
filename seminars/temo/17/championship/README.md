# Championship (20 ქულა)
თქვენი ამოცანაა იმპლემენტაცია გაუკეთოთ `FindWinner` ფუნქციას, რომელმაც უნდა დაადგინოს და დააბრუნოს იმ გუნდის ნომერი რომელმაც ყველაზე მეტი ქულა დააგროვა შეჯიბრში.

შეჯიბრში მონაწილეობს სულ 10 გუნდი, რომლებიც გადანომრილი არიან 0-დან 9-ის ჩათვლით. თამაშების შედეგები მოცემული გაქვთ როგორც ბაიტების მიმდევრობა, რომელიც ბოლოვდება ნულოვანი ბაიტით.
ერთი თამაშის აღსაწერად გამოყენებულია ერთი ბაიტი. ბაიტის მაღალი ინდექსის ორი ბიტი აღნიშნავს თამაშის შედეგს, მომდევნო სამი ბიტი პირველი გუნდის ნომერს, ხოლო ბოლო სამი ბიტი მეორე გუნდის ნომერს. `00` აღნიშნავს ფრეს, `01` აღნიშნავს რომ პირველმა გუნდმა მოიგო, ხოლო `10` აღნიშნავს რომ მეორე გუნდმა მოიგო.

ფრეს შემთხვევაში ორივე გუნდს ეწერება ერთი ქულა, წინააღმდეგ შემთხვევაში მოგებული გუნდი იღებს 3 ქულას ხოლო წაგებული 0-ს.
შეჯიბრს იგებს ის გუნდი რომელმაც ყველაზე მეტი ქულა დააგროვა, გარანტია გაქვთ რომ ასეთი მხოლოდ ერთია.

მაგალთად ბაიტი 10010111 ნიშნავს რომ ერთმანეთს შეხვდა ნომრით მეორე (`010`) და მეშვიდე (`111`) გუნდები, ხოლო გაიმარჯვა რიგით მეშვიდე გუნდმა `10`.
